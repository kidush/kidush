## Open-source projects

### Omarchy and the Linux desktop

| Project | What it does |
|---------|--------------|
| [remote-control](https://github.com/kidush/remote-control) | Control an IR air conditioner from the Omarchy bar, the CLI and Hyprland shortcuts, through a Tuya IR blaster. Go daemon + Quickshell widget. |
| [omarchy-aula-f108pro](https://github.com/kidush/omarchy-aula-f108pro) | Omarchy bar plugin and Linux CLI for the AULA / Alma F108 Pro keyboard: LCD dashboard mirror, backlight, battery and clock sync over its 2.4 GHz dongle. |
| [hypr-wallpaper](https://github.com/kidush/hypr-wallpaper) | TUI wallpaper picker for Hyprland with live image previews and vim-style navigation. |
| [golin](https://github.com/kidush/golin) | rcmd-style app switcher for KDE Plasma Wayland: `Meta+<letter>` focuses or launches the mapped app. |
| [gather-linux-port](https://github.com/kidush/gather-linux-port) | Community Linux port of the Gather desktop app. |
